This project contains 10 Python case studies for first-year B.Tech. The
examples include college marks, electricity bills, and festival expenses.
They use basic topics such as loops, conditions, strings, lists, and tuples.

## Running the programs

To run all the programs and their tests from this folder:

```bash
python run_all_case_studies.py
```

To run one case study, open its folder and run the program and tests. For
example:

```bash
cd Case_Study_01_University_Scholarship_Allocation
python problem_01_scholarship_allocation.py
python test_cases.py
```

## Other files
